# Proyecto Almanaque — Constitución

Principios innegociables. Toda spec, plan y tarea debe cumplirlos

1. Stack Cerrado: Backend exclusivo en Python (Pandas + FastAPI/Uvicorn/Pydantic para la API) y Frontend en React (Tailwind).

2. Inmutabilidad: Los archivos crudos en /data son de solo lectura. Estrictamente prohibido modificarlos.

3. Idioma Dual: Lógica, variables y archivos en inglés. Interfaz y mensajes al usuario en español.

4. Tests Obligatorios: Toda nueva funcionalidad debe validarse con pytest o Vitest antes de cerrarse.

5. Cero Improvisación: Prohibido añadir librerías o escribir código sin una Spec aprobada.

6. Simplicidad: Código directo y legible; evitar abstracciones y arquitecturas complejas innecesarias.
